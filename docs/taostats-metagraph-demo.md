# Synthetic offline Metagraph Demo (PR #5H)

Демонстрация использует только встроенную вымышленную fixture. Это учебные
значения, **не реальные данные Bittensor или Taostats**. Существующие HTML demo,
CLI и Windows Sheets launcher не изменены и новым demo не запускаются.

## Запуск в Windows PowerShell

Нужен Python 3.10+ с launcher `py` и пакет `taostats-pipeline`, уже установленный
в выбранном этим launcher Python-окружении. Установка проекта описана в README;
сам demo ничего не устанавливает и не загружает. Команда работает независимо
от текущей директории:

```powershell
py -m taostats_pipeline.api_v1_demo
```

Краткая справка:

```powershell
py -m taostats_pipeline.api_v1_demo --help
```

Demo принимает только отсутствие аргументов или отдельный --help/-h. Параметров
--live, URL, credentials, --input, --output, --apply и Sheets-команд нет.
Не передавайте секреты в командной строке. Неизвестные аргументы отклоняются
без повторения их значений в stdout/stderr.

Результат печатается только в stdout, без логов и файлов результата. Demo не
меняет окружение, не читает API-ключи и не создаёт Transport. Для запуска не нужны
Google зависимости, браузер, API-ключ или доступ к сети.

## Пример результата

```json
{
  "status": "ok",
  "mode": "offline",
  "synthetic": true,
  "message": "Synthetic demo only; not real Bittensor data.",
  "netuid": 7,
  "block": 1000,
  "record_count": 6,
  "vtrust_avg": "0.35000000000000000000000000001",
  "vtrust_computed": true
}
```

status=ok означает только успешную проверку учебной fixture, а не состояние
реальной подсети. netuid, UID и block — произвольно выбранные учебные числа;
они не описывают какой-либо реальный снимок. Адресов, hotkeys и credentials нет.
block — номер блока из вымышленного примера, а не timestamp.

## Данные и расчёт

Ресурс fixtures/metagraph-demo.json загружается через importlib.resources.
Текущий package-data уже включает fixtures/*.json, поэтому ресурс доступен
установленному пакету. Metadata с synthetic=true, описанием, netuid и
expected_block отделены от API envelopes/records. Маркер должен быть именно
boolean true; отсутствие или другая величина приводят к отказу.

Шесть вымышленных строк распределены по двум полным страницам. Четыре строки
имеют active=true AND validator_permit=true с validator_trust:

- 0;
- 0.2;
- 0.4;
- 0.80000000000000000000000000004.

Их сумма 1.40000000000000000000000000004. Деление на 4 даёт
0.35000000000000000000000000001. Нулевое значение входит в знаменатель.
Одна дополнительная строка с trust=0.99 неактивна; другая с trust=0.6 не имеет
permit. Обе исключаются из среднего. Эти значения созданы для демонстрации
фильтров и точности, а не взяты из старого ожидаемого среднего или реального API.

Метрики в fixture записаны десятичными строками. Их bounded Decimal-разбор и
среднее выполняются существующими mapper/orchestration; демо не копирует формулу.
Выходной Decimal превращается в строку, без float. JSON null соответствует
отсутствующему среднему; vtrust_computed=true отличает его от пропуска вычисления.
Тест независимо пересчитывает среднее рациональной арифметикой Fraction.

Путь обработки: fixture -> complete_metagraph(..., budget=Budget(2, 2)) ->
analyze_metagraph(..., netuid=7, expected_block=1000) -> JSON. Значения netuid
и блока передаются из metadata; результат содержит поля настоящего анализа,
а не заранее записанное среднее. Incentive в этом demo не вычисляется.

## Ошибки и ограничения

Коды завершения: 0 — успешное demo или справка; 1 — ошибка загрузки/проверки;
2 — неподдерживаемые аргументы. В PowerShell код доступен через $LASTEXITCODE.
Ошибки обработки и аргументов выводятся одним коротким JSON с полями status=error,
mode=offline, synthetic=true, message. Частичных метрик, исходных исключений,
тел fixture, путей или переданных пользователем значений в сообщении нет.
Справка --help является обычным текстом, а не JSON.

Неполные страницы, дубликаты UID, несовпадающий блок, отсутствующие обязательные
метрики и неподтверждённая synthetic-маркировка не дают успешного отчёта.
Среднее и масштаб VTrust здесь соответствуют проектной методике и не доказывают
формулу интерфейса Taostats. Сетевого режима или автоматического fallback нет.

Offline-тесты вызывают main() и module entry point без дочерних процессов,
проверяют installed-package resource из другой директории, отсутствие файлов,
блокируют сеть, создание Transport, fetch_metagraph и чтение credentials.
Фактический executable py/PowerShell не запускается из pytest, где subprocess
запрещён; используется тот же Python module entry point. Новых зависимостей нет.
